# Planos de teste

Planos em Markdown escritos pelo agente `playwright-test-planner` (ou à mão) antes de virar código.
Um arquivo por funcionalidade, por exemplo `monitoramento-energia.md`, com cenários de sucesso,
erro, permissão e validação. O agente `playwright-test-generator` transforma cada cenário em um
teste em `e2e/specs/<área>/`. Veja `e2e/README.md`, seção "Testes com auxílio de IA".
