# Referência visual e origem da imagem

A fachada em `packages/ui/src/assets/condominio-noite.png` foi gerada para este projeto em 21/09/2026. É uma imagem decorativa de condomínio genérico; não representa um prédio cadastrado nem uma câmera ao vivo. Usada na barra lateral, na carteira e no cabeçalho do portal do morador.

Modo: geração de imagem nova com ImageGen. Sem edição das imagens enviadas pelo usuário. Formato: PNG, 1024 × 1536.

Prompt utilizado:

> Create a photorealistic architectural photograph for a Brazilian condominium management web app. One modern elegant mid-rise residential apartment building at blue hour, navy blue dusk sky, warm golden interior lights in balconies, concrete, glass and subtle landscaped tropical greenery at the base. Portrait composition 1024 by 1536, entire building visible, building centered slightly to the right, dark navy negative space along upper left for interface overlay. Sophisticated realistic architectural photography, natural lighting, clean composition. Absolutely no text, logos, signage, watermarks, people, vehicles or UI. This is a decorative generic building image, not a specific real property.

As imagens 2, 4 e 6 recebidas do usuário orientam os dashboards; 3 e 5, a apresentação móvel. As imagens 1 e 7 são material publicitário e orientam apenas identidade e fotografia. A interface mantém somente os módulos existentes e os dados da API. Não há comandos para abrir portões.
